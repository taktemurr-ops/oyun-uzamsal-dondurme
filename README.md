# Uzamsal Döndürme · Spatial Rotation

Ayna görüntüsüne aldanma!

Üstteki şeklin yalnızca döndürülmüş hali seçeneklerden birindedir; diğerleri ayna görüntüsüdür. Şekli zihninde çevir ve doğru olanı seç. On soru, sınırlı hak.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Zihin Antrenmanı merkez uygulamasının oyunu; ortak motor: [zihin-motoru](https://github.com/taktemurr-ops/zihin-motoru).
